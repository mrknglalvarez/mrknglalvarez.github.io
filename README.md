# Angelo Alvarez — IT Systems & Digitalization Portfolio

GitHub Pages-ready portfolio using plain HTML, CSS and JavaScript.

## Files

- `index.html` — page structure and project content
- `style.css` — responsive visual design
- `script.js` — mobile navigation, scroll reveal and active navigation
- `assets/` — place project screenshots, resume and other assets here

## Publish on GitHub Pages

1. Create or open `mrknglalvarez.github.io`.
2. Replace the existing `index.html`, `style.css`, and `script.js` with these files.
3. Put project screenshots inside `assets/`.
4. Commit and push.
5. In GitHub: Settings → Pages → Deploy from branch → `main` / root.

## Before publishing

Replace:
- `your-email@example.com`
- Any placeholder profile information
- Project screenshots and links
- Experience details if you want exact employment dates

## Replacing project screenshots

The Featured Projects section now uses these placeholder images:

- `assets/projects/qa-defect-dashboard.svg`
- `assets/projects/training-record-system.svg`
- `assets/projects/mold-qr-system.svg`
- `assets/projects/it-purchase-system.svg`

Replace each SVG with your actual screenshot. You can use PNG or JPG; keep the same filename by converting your image to `.png`/`.jpg` and update the `<img src="...">` in `index.html`.

Recommended screenshot format:
- 16:9 or close to 16:9
- 1400px wide or higher
- Crop out browser/toolbars when possible
- Remove confidential employee names, email addresses, IP addresses and company-sensitive information
