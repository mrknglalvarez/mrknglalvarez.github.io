# Mark Angelo C. Alvarez — Premium IT Portfolio

Premium responsive portfolio for `mrknglalvarez.github.io`.

## Visual direction

The redesign uses a **white / deep navy / electric blue / cyan** palette. The goal is a clean executive-technology look: professional enough for recruiters and employers, but still clearly an IT portfolio.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Manrope + DM Sans
- GitHub Pages compatible
- No build tools or framework required

## Sections

- Hero / professional positioning
- About
- Core IT expertise
- Professional experience
- Selected work
- Education and certifications
- Contact

## Publish

Upload these files to the root of `mrknglalvarez.github.io`:

- `index.html`
- `style.css`
- `script.js`
- `profile.jpg`
- `Alvarez_Resume.pdf`

Then enable GitHub Pages from repository Settings → Pages.

## Public information

The page intentionally does not display the full home address or phone number from the resume. The resume PDF is included separately so you can decide whether you want it publicly downloadable.

## Source

Portfolio content is based on the supplied professional resume. Project descriptions are kept within the scope of the information provided.
